A model is a function, where it has an input, an Action, and an output, and it forgets the input and output once complete (outputted), therefore, every model has its independent input, and cannot be transferred across other model calls. This is what happend in two_calls, where one model knew my name included in the input, while the other model did not.

The alternative is by having multiple calls in one model through an array, where the input includes all text from the conversation, including what the model previously said which we could engineer ourselves by manually typing in past replies into this Array, then the model everytime it produces an output re-reads the history of inputs for it to remember, though it is expensive and can be slow as things pile up - this was the case in conversation.py where we added another line of a "past input and output" into the input that included my name.
